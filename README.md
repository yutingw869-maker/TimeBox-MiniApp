# 时光盒 (Time Box) - AI 驱动的全栈共享相册小程序

## 🌟 项目简介
本项目是一个基于微信小程序云开发（Serverless）实现的共享相册应用。项目采用 **Vibe Coding (AI 辅助编程)** 模式，利用 Gemini 1.5 Pro 进行架构设计与逻辑调试，实现了从需求定义到 ICP 备案落地的全流程。

## 🚀 核心功能
- **共享机制**：基于 UUID 生成全球唯一邀请码，支持多用户加入同一相册。每创建一个相册会生成唯一的邀请码，分享该邀请码即可实现与好友共享相册。
- **云端存储**：集成微信云存储，支持图片流式上传与高清预览。
- **交互设计**：玻璃拟态（Glassmorphism）UI 设计，支持长按删除、时间轴聚类展示。
- **安全隔离**：通过数据库 Collection 级安全规则，实现“全员可读、创建者可改”的权限控制。

## 🛠️ 技术栈
- **前端**: 微信小程序原生框架 (WXML / WXSS / JavaScript)
- **后端**: 微信云开发 (Node.js 云函数)
- **数据库**: 云开发 NoSQL 数据库
- **AI 工具**: Gemini 1.5 Pro, github copilot (用于逻辑排障、安全规则编写)

## 📈 AI 开发实践 (Landing Insights)
在本项目开发中，AI 不仅用于编写基础代码，更在以下复杂场景中提供了关键支持：
1. **权限策略调试**：通过 AI 辅助编写 JSON 格式的数据库高级安全规则，解决了多用户共享场景下的数据越权访问问题。
2. **交互冲突排查**：定位并解决了 `bindlongpress` 与样式层级 `z-index` 导致的事件拦截 Bug。
3. **部署路径优化**：在处理学生异地备案及云环境配置报错时，利用 AI 快速定位环境关联问题。

## 📦 快速开始
1. 克隆本项目到本地。
2. 使用微信开发者工具打开，导入项目。
3. 修改 `app.js` 中的 `env` 为你自己的云开发环境 ID。
4. 在云开发后台创建 `albums`、`photos`、`members` 三个集合。
5. 设置集合权限为：`所有用户可读，仅创建者可读写`。
